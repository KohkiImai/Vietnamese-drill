# ベトナム語ドリル

ベトナム語と日本語の文を見て、正しい答えを2つの中から選ぶクイズです。
約60語の基本単語を組み合わせて作った100問が入っています。

出題の向きは、画面のボタンで切り替えられます。

- **ベトナム語 → 日本語**：ベトナム語の文を見て（聞いて）、正しい日本語を選ぶ
- **日本語 → ベトナム語**：日本語の文を見て、正しいベトナム語を選ぶ

URL：`https://ユーザー名.github.io/vietnamese-drill/`

GitHub Pages で公開しているので、スマホのブラウザから使えます。ホーム画面に追加すると、アプリのようにアイコンから起動できます。一度開けば、電波がない場所でも使えます。

## 問題の構成

同じ単語をくり返し使うので、「私は駅に行く／彼は駅に行く／妹は学校から帰る」のように、1語ずつ入れ替えながら覚えられます。

| セット | 内容 | 問題数 |
|---|---|---|
| 1. 行く・帰る | đi đến（〜に行く）、về（帰る）、từ 〜 về（〜から帰る） | 20 |
| 2. 食べる・飲む | ăn（食べる）、uống（飲む）、ở（〜で） | 20 |
| 3. 買う・好き・勉強する | mua、thích、học、đọc | 20 |
| 4. 否定・質問 | không（〜ない）、đâu（どこ）、gì（何）、có 〜 không?（〜しますか？） | 20 |
| 5. 様子・もう〜した・〜して | rất（とても）、rồi（もう〜した）、và（そして）、với（〜と） | 20 |

このほかに「全体からランダム（20問）」と「全100問」も選べます。

## 機能

- **クイズ**：2択で答えます。「ベトナム語 → 日本語」と「日本語 → ベトナム語」をボタンで切り替えられます（最後に選んだ向きを覚えています）。間違いの選択肢には、正解とよく似た文（同じ単語を使った文）が出るので、主語・場所・動詞を1語ずつ確かめる練習になります。最後に点数と間違えた文が表示され、「間違えた問題だけもう一度」で復習できます。
- **一覧**：選んだセットの文をベトナム語と日本語で一覧表示します。
- **単語**：使っている単語を「人・場所・動作・もの・様子・その他」に分けて表示します。
- **読み上げ**：🔊ボタンでベトナム語を読み上げます。「自動で読み上げ」をオンにすると、自動で読み上げます。「ベトナム語 → 日本語」では問題が出たとき、「日本語 → ベトナム語」では答えがわかってしまわないように答えたあとに、正解のベトナム語を読み上げます。速さは「ふつう」と「ゆっくり」から選べます。
- PCでは数字キーの「1」「2」で答え、「Enter」で次の問題に進めます。

## 読み上げについて

読み上げには、スマホやPCに入っている音声合成機能を使います。

- **iPhone**：ベトナム語の音声が最初から入っているので、そのまま使えます。マナーモードだと音が出ないことがあります。
- **Android**：「設定 → テキスト読み上げ」で、Googleの音声エンジンにベトナム語を追加してください。
- **Windows**：「設定 → 時刻と言語 → 音声」から、ベトナム語の音声を追加してください。追加していないと、日本語や英語の声で読まれて正しい発音になりません。

## 問題を追加・修正するには

問題を直すときは `sentences.js` だけを編集します。`index.html` は触らなくて大丈夫です。

`const SETS = [` から始まる部分が問題のリストです。1行に1問ずつ、次の形で並んでいます。

```js
["Tôi đi đến nhà ga.", "私は駅に行く。"],
```

左がベトナム語、右が日本語です。同じ形の行を追加・修正してください。行の最後の `,` や `"` を消すとアプリが表示されなくなるので注意してください。

単語の一覧は、その下の `const VOCAB = [` からの部分です。

修正したあとにスマホで古い内容が表示される場合は、`sw.js` の2行目にある `vi-drill-v6` の数字を1つ増やして（例：`vi-drill-v7`）一緒にアップロードしてください。
