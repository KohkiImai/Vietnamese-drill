# ベトナム語ドリル

ベトナム語と日本語の文を見て、正しい答えを2つの中から選ぶクイズです。
同じ単語をくり返し使う例文で、1語ずつ入れ替えながら覚えられます。

出題の向きは、画面のボタンで切り替えられます。

- **ベトナム語 → 日本語**：ベトナム語の文を見て（聞いて）、正しい日本語を選ぶ
- **日本語 → ベトナム語**：日本語の文を見て、正しいベトナム語を選ぶ

URL：`https://ユーザー名.github.io/vietnamese-drill/`

GitHub Pages で公開しているので、スマホのブラウザから使えます。ホーム画面に追加すると、アプリのようにアイコンから起動できます。一度開けば、電波がない場所でも使えます。

## レベル

画面の「レベル」と「セット」で問題を選びます。各レベルには「このレベルからランダム（20問）」と「このレベルの全問」もあります。

| レベル | セット数 | 問題数 | 単語数の目安 | 内容 |
|---|---|---|---|---|
| 超初級 | 5 | 100 | 約60語 | 行く・帰る、食べる・飲む、否定・質問など |
| 初級 | 35 | 700 | 約540語（新出） | 数字・時間・曜日、家族、自己紹介、〜したい・〜できる・〜している・〜した・〜する予定、買い物、レストラン、交通、道案内、天気、体調、比較、仕事、趣味、気持ち、電話、経験など |

今後、中級・上級を追加する予定です。

## 機能

- **クイズ**：2択で答えます。間違いの選択肢には、同じレベルの中から正解とよく似た文（同じ単語を使った文）が出るので、主語・時・場所・動詞を1語ずつ確かめる練習になります。最後に点数と間違えた文が表示され、「間違えた問題だけもう一度」で復習できます。
- **一覧**：選んだセットの文をベトナム語と日本語で一覧表示します。
- **単語**：超初級は使っている単語を種類ごとに、初級はセットごとに新しく出てくる単語を表示します。
- **読み上げ**：🔊ボタンでベトナム語を読み上げます。「自動で読み上げ」をオンにすると、自動で読み上げます。「ベトナム語 → 日本語」では問題が出たとき、「日本語 → ベトナム語」では答えがわかってしまわないように答えたあとに、正解のベトナム語を読み上げます。速さは「ふつう」と「ゆっくり」から選べます。
- PCでは数字キーの「1」「2」で答え、「Enter」で次の問題に進めます。

## 読み上げについて

読み上げには、スマホやPCに入っている音声合成機能を使います。

- **iPhone**：ベトナム語の音声が最初から入っているので、そのまま使えます。マナーモードだと音が出ないことがあります。
- **Android**：「設定 → テキスト読み上げ」で、Googleの音声エンジンにベトナム語を追加してください。
- **Windows**：「設定 → 時刻と言語 → 音声」から、ベトナム語の音声を追加してください。追加していないと、日本語や英語の声で読まれて正しい発音になりません。

## 問題を追加・修正するには

直したいレベルのファイル（`level0.js` や `level1.js`）だけを編集します。`index.html` は触らなくて大丈夫です。

問題は1行に1問ずつ、次の形で並んでいます。

```js
["Tôi đi đến nhà ga.", "私は駅に行く。"],
```

左がベトナム語、右が日本語です。同じ形の行を追加・修正してください。行の最後の `,` や `"` を消すとアプリが表示されなくなるので注意してください。

各セットには、`name`（セット名）、`note`（ポイントの説明）、`items`（問題）があります。初級には `words`（そのセットで新しく出てくる単語）もあります。

修正したあとにスマホで古い内容が表示される場合は、`sw.js` の2行目にある `vi-drill-v7` の数字を1つ増やして（例：`vi-drill-v8`）一緒にアップロードしてください。

## 新しいレベルを追加するには

1. `level1.js` をコピーして `level2.js` を作り、1行目近くの `name: "初級"` を `name: "中級"` に変えて、問題を入れ替えます。
2. `index.html` の `<script src="level1.js"></script>` の次の行に、`<script src="level2.js"></script>` を追加します。
3. `sw.js` の `FILES` の一覧に `"level2.js"` を追加し、`vi-drill-v7` の数字を1つ増やします。
